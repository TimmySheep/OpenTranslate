## 改动 2：PBXFileReference 段追加 settings 文件夹引用

**锚点原文（整行，仅出现一次）：**

```
		11EEF9092FE586BB003E1F8A /* OpenTranslate.entitlements */ = {isa = PBXFileReference; lastKnownFileType = text.plist.entitlements; path = OpenTranslate.entitlements; sourceTree = "<group>"; };

**插入位置：** 锚点之后、`/* End PBXFileReference section */` 之前。

**要插入的内容：**

```
